# API документация

`openapi.json` содержит описание API в формате OpenAPI 3. Файл встроен в приложение через `go:embed`. После запуска сервиса Swagger UI доступен по адресу `http://localhost:8080/swagger/`.

Спецификация поддерживается вручную. Swagger UI загружает свои файлы через CDN, поэтому для интерфейса нужен интернет.
